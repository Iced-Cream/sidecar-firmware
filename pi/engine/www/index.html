Wi-Fi

Network-

Sidecar uses one network at a time: Connect and save stores the network and restarts Sidecar on Wi-Fi (the sound stops for a few seconds; Ethernet is unused while it is on Wi-Fi). If it is not connected within 90 s, the previous setting comes back and Sidecar restarts on it (Ethernet, if Wi-Fi was off), so a wrong password cannot lock you out. This page follows to the Wi-Fi address at sidecar.local when this computer is on that network. The password is stored only as the network's key, never shown again; this page has no login yet; the pairing code under Access is what keeps someone else on this network out.

Access

Pairing code-
This device-

Sidecar shows an 8-digit code on the Rytm's screen. Entering it once lets this browser change things; reading the status and the log never needs it. A remembered device keeps working after Sidecar restarts, and Forget makes it ask for the code again. Forget every device also ends every other browser's and sdboot.py's access. The code is not encryption: this page is plain HTTP on your network, so treat the network itself as the lock.

Rytm MIDI bridge

Bridge-
Traffic-
Token

The Rytm's USB MIDI on TCP port 7330, for test tools on a computer (analogrun, analogusb.py, elkbench): everything the Rytm sends is copied to the tool, and the tool's messages go to the Rytm between Sidecar's own. It is off at every start, a tool must answer a challenge with the token (new at every turn-on), and Elektron OS upgrades and +Drive writes are refused unless the boxes above are ticked. On the computer run SIDECAR_BRIDGE_TOKEN=<token> python3 tools/rytm_bridge.py --pi sidecar.local and point the tool at tcp:127.0.0.1:7321 (docs/HARDWARE-TESTING.md). Forgetting every device turns the bridge off.

Storage

SD card-


      
USB drives (FAT32; a stick with the MBR scheme) mount when plugged in; Eject before pulling one.
        The bench writes and reads a 256 MB file on the drive (removed afterwards), then random reads, the raw device and
        reads while the Overbridge stream runs: a few minutes on the SD card, under a minute on a fast drive. It is refused
        while the Rytm plays or records; the sound may drop out while it runs on the SD card. Same as the console's
        stor=bench:USB; details in docs/STORAGE.md.

About

      

      
Sidecar | Expander, a generic engine beside the drum machine: the host link's services (the
        screen, the clock, the store, the card browse, the USB-A MIDI devices, the processor slots on the audio return).
        Core 0 runs the network (this page), USB (Overbridge, USB-C) and the card; core 3 is the control core. The page
        never waits on the engine: a request is answered from what the cores last published.

    

  

  

    

      
Pairing code

      
Sidecar asks for a code before this page may change anything. It is on the Rytm's screen, and it changes every time Sidecar restarts.

      

        

      

      

        

      

      

      
The status and the log are readable without the code, so you can watch Sidecar while it is
        unpaired. Several wrong codes lock pairing for a while.
